പ്രതിമാസ വരിസംഖ്യ (Monthly Vari)

ഓരോ കുടുംബത്തിന്റെയും പ്രതിമാസ കുടിശ്ശിക കൃത്യമായി രേഖപ്പെടുത്താനും രസീത് നൽകാനും വാട്സാപ്പ് വഴി ഓർമ്മപ്പെടുത്തൽ അയക്കാനും സാധിക്കുന്നു.

അഡീഷണൽ കളക്ഷൻ (Special Funds)

മദ്റസ നിർമ്മാണം, മെഡിക്കൽ റിലീഫ്, റമദാൻ കിറ്റ് തുടങ്ങി പ്രത്യേക ഫണ്ടുകൾ സബ് അഡ്മിന് ഉണ്ടാക്കാനും വരിസംഖ്യ പിരിക്കാനും സാധിക്കുന്നു.

കുടുംബ വിവര ശേഖരണം (Family Registry)

സബ് അഡ്മിൻ കുടുംബത്തെ ആഡ് ചെയ്താൽ, കുടുംബങ്ങൾക്ക് OTP വഴി ലോഗിൻ ചെയ്ത് തങ്ങളുടെ പ്രൊഫൈൽ എളുപ്പത്തിൽ പൂർത്തിയാക്കാം. സബ് അഡ്മിൻ വെരിഫിക്കേഷനും ലഭ്യമാണ്.

📱 ഫോണിൽ എങ്ങനെ ഇൻസ്റ്റാൾ ചെയ്യാം?

  1. മുകളിലുള്ള "Download APK" ബട്ടൺ ക്ലിക്ക് ചെയ്ത് APK ഫയൽ ഫോണിലേക്ക് ഡൗൺലോഡ് ചെയ്യുക.
  2. ഡൗൺലോഡ് ചെയ്ത ഫയൽ ഓപ്പൺ ചെയ്യുമ്പോൾ "Install unknown apps" അല്ലെങ്കിൽ "Allow from this source" എന്ന് ചോദിച്ചാൽ Allow (സമ്മതം) നൽകുക.
  3. തുടർന്ന് Install ബട്ടൺ ക്ലിക്ക് ചെയ്യുക.
  4. ആപ്പ് ഓപ്പൺ ചെയ്ത് സബ് അഡ്മിൻ നൽകിയ ഫോൺ നമ്പർ അടിച്ച് ലഭിക്കുന്ന OTP വഴി ലോഗിൻ ചെയ്യുക.
ശ്രദ്ധിക്കുക: ഈ ആപ്ലിക്കേഷൻ ആൻഡ്രോയിഡ് ഫോണുകൾക്ക് വേണ്ടിയുള്ള മൊബൈൽ ആപ്പാണ്. ബ്രൗസറിൽ നേരിട്ട് വെബ്സൈറ്റായി പ്രവർത്തിക്കില്ല. ഫോണിൽ APK ഇൻസ്റ്റാൾ ചെയ്ത് ഉപയോഗിക്കുക.
