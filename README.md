## 🚀 പ്രധാന സവിശേഷതകൾ (Key Features)

1. **📊 ഡാഷ്‌ബോർഡ് (Overview):**
   - കൈവശമുള്ള ബാക്കി തുക (Net Cash In Hand), വരിസംഖ്യാ വരുമാനം, മറ്റ് വരവുകൾ, ചിലവുകൾ, കുടിശ്ശിക തുക എന്നിവ ഒറ്റനോട്ടത്തിൽ.
   - സമീപകാല രസീതുകളും ഇടപാടുകളും.

2. **💳 വരിസംഖ്യ & കുടുംബങ്ങൾ (Subscriptions):**
   - എല്ലാ കുടുംബങ്ങളുടെയും 12 മാസത്തെ വരിസംഖ്യാ നില (Jan-Dec Matrix).
   - ഒറ്റ ക്ലിക്കിൽ മാസങ്ങൾ തിരഞ്ഞെടുത്ത് വരിസംഖ്യ സ്വീകരിക്കലും ഡിജിറ്റൽ രസീത് നൽകലും.
   - വാട്സാപ്പ് വഴി കുടിശ്ശിക ഓർമ്മപ്പെടുത്തൽ മെസ്സേജ് (WhatsApp Reminder).
   - മദ്റസാ നിർമ്മാണം, റിലീഫ് ഫണ്ടുകൾ തുടങ്ങിയ പ്രത്യേക ഫണ്ടുകൾ (Special Funds).

3. **📖 വരവ് - ചിലവ് ലെഡ്ജർ (Cash Ledger):**
   - കാറ്റഗറി, വൗച്ചർ നമ്പർ, പേയ്‌മെന്റ് മോഡ് എന്നിവയോടെ പൂർണ്ണമായ വരവ്-ചിലവ് കണക്കുകൾ.
   - തരം തിരിച്ചുള്ള ഫിൽട്ടറുകൾ.

4. **🛡️ സുതാര്യത & പൊതു ഓഡിറ്റ് (Transparency & Audit):**
   - പൊതുജനങ്ങൾക്ക് സ്വന്തം വീട്ടുനമ്പറോ ഫോൺ നമ്പറോ അടിച്ച് കുടിശ്ശികയും രസീതുകളും പരിശോധിക്കാനുള്ള സൗകര്യം.
   - ചിലവുകളുടെ ശതമാനക്കണക്കും പ്രിന്റ് ചെയ്യാവുന്ന ഓഡിറ്റ് റിപ്പോർട്ടും.

5. **⚙️ ബാക്കപ്പ് & സെറ്റിങ്സ്:**
   - കമ്പ്യൂട്ടറിലേക്ക് പൂർണ്ണ ഡാറ്റ ബാക്കപ്പ് ഡൗൺലോഡ് ചെയ്യാനും റീസ്റ്റോർ ചെയ്യാനുമുള്ള JSON ബാക്കപ്പ് സൗകര്യം.
   - Excel / CSV ഫോർമാറ്റിൽ കുടുംബങ്ങളുടെ ലിസ്റ്റ് ഡൗൺലോഡ് ചെയ്യാം.
